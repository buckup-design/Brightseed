## About

This is the working home for Quill, the design system behind Brightseed's digital design surfaces. Here you'll find the brand-themed React components and patterns that serve as the building blocks of the interface.

The thinking behind this workflow comes from TJ Pitre's work on AI-powered design systems. By default, AI tools build new components from scratch every time. That sounds convenient, but it means each screen reinvents buttons, inputs, and layouts slightly differently: drifting off-brand, skipping the accessibility and responsive behavior our real components already handle, and producing markup that doesn't match production. It looks plausible in a demo but shouldn't actually ship, and it quietly multiplies inconsistency and maintenance debt.

A design system (component library, token system, and layout patterns) is the source of truth, so when AI generates a screen it assembles from pieces that already exist, are already on-brand, and are already built for responsiveness and accessibility.

## What is Storybook?

Storybook is a library of our UI components and the different states they can be in. Normally, to see a component you'd have to run the whole app, click your way to the right screen, and force it into the state you want to look at. Storybook skips all of that. Every component and variation lives on its own page, ready to view, compare, and interact with. That makes it just as useful for reviewing and designing as it is for building. [Learn more →](https://storybook.js.org/docs/get-started/why-storybook)

## Status

This is an early-stage experiment, not yet an official v1. We're still actively adding components and refining the workflow, so expect things to change. What you see here is always current: the published Storybook refreshes automatically whenever work lands on the main branch.

## How this is organized

The left sidebar runs from the raw materials up to full product screens:

- **Foundations:** the design tokens, color scales, typography, logo, and icons everything else is built on.
- **Components:** the core UI building blocks (buttons, badges, inputs, tables, and more), styled to the Brightseed brand.
- **Blocks:** larger, pre-composed pieces like application shells and navigation.
- **DRAFT WIP:** product surfaces (cards and screens), in progress, assembled from the components above.
- **Auth:** the sign-in patterns.

Start at the top for the building blocks, or jump to DRAFT WIP to see them assembled into real screens.

## Components

This system uses [shadcn/ui](https://ui.shadcn.com) as its foundational set of components. Those base components have been restyled to match the Brightseed brand, and additional custom components have been added to meet our specific product needs.

Click any component in the sidebar to open its page. A few things to know:

- **Docs tab:** a written overview of the component with live, interactive examples.
- **Stories:** each story (listed under the component) shows it in a specific state or variation, so you don't have to recreate it yourself.
- **Controls:** the panel beneath a story lets you change its properties live (text, size, state) to try variations without touching code.
- **Light / dark toggle:** the sun/moon control in the top toolbar switches the whole view between themes, so you can check both.
